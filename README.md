# E-Bookshop Management System 📚

A console-based E-Bookshop Management System developed in C++ to demonstrate the practical implementation of Data Structures and Algorithms.

## Features
- Book Management: Add, delete, search, and display books.
- Visitor Suggestions: Manage suggestions using a Stack.
- Leadership Management: Add, delete, and search for leaders.
- Technical Support: Process support requests using a Queue.

## Data Structures Used
- **Sorted Array:** Book management with Binary Search.
- **Stack (LIFO):** Visitor suggestions.
- **Unsorted Array:** Leadership management.
- **Linked List Queue (FIFO):** Technical support requests.
- **Templates:** Generic implementation of data structures.

## Technologies
- C++
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms

## How to Run
1. Download or clone the repository.
2. Open the C++ source file in a C++ IDE or compiler.
3. Compile and run the program.
4. Follow the console menu to use the system.

## Project Purpose
This project was developed to apply fundamental data structures and algorithms in a practical C++ application.
